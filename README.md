# 🌡️ Temperature Converter Website

This is a simple and interactive temperature converter web application built using HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

The design is clean and user-friendly, with playful UI elements and responsive styling. This project helped me practice DOM manipulation, event handling, and basic JavaScript logic.

## 💻 Features

- Convert between Celsius, Fahrenheit, and Kelvin
- Real-time conversion as users input values
- Clear and intuitive layout
- Responsive design for mobile and desktop
- Styled with CSS for a modern look

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)


## 📂 How to Use

1. Enter a temperature value in any one of the input fields.
2. The other fields will automatically update with the converted values.
3. Works for Celsius, Fahrenheit, and Kelvin.
